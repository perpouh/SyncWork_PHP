# defineProps

[公式ドキュメント](https://ja.vuejs.org/guide/components/props)

## 概要
Vue 3のComposition APIにおける`defineProps()`の使い方と、重要な仕様について説明します。

## 基本的な書き方

### 1. 戻り値を変数に代入する方法
```vue
<script setup>
// 基本的な書き方
const props = defineProps(['title', 'count'])

// オブジェクト形式での詳細定義
const props = defineProps({
  title: String,
  count: {
    type: Number,
    default: 0
  }
})

// TypeScriptでの型定義
const props = defineProps<{
  project: Project;
  tickets: Ticket[];
}>()
</script>
```

### 2. 分割代入を使用する方法
```vue
<script setup>
// 分割代入で個別の変数として使用
const { title, count } = defineProps(['title', 'count'])

// TypeScriptでの分割代入
const { project, tickets } = defineProps<{
  project: Project;
  tickets: Ticket[];
}>()
</script>
```

## 重要な仕様：テンプレート内での自動アクセス

### テンプレート内では戻り値を代入しなくてもアクセス可能
```vue
<script setup>
// 戻り値を変数に代入していない
defineProps<{
  projects: Project[];
  status?: string;
}>();
</script>

<template>
  <!-- テンプレート内では直接アクセス可能 -->
  <div v-for="project in projects" :key="project.id">
    <h2>{{ project.title }}</h2>
    <p>Status: {{ status || 'No status' }}</p>
  </div>
</template>
```

### スクリプト内とテンプレート内の違い
```vue
<script setup>
defineProps<{ projects: Project[] }>();

// ❌ スクリプト内ではアクセスできない
// console.log(projects); // ReferenceError: projects is not defined

// ✅ 変数に代入すればスクリプト内でもアクセス可能
const props = defineProps<{ projects: Project[] }>();
console.log(props.projects); // アクセス可能
</script>

<template>
  <!-- ✅ テンプレート内では直接アクセス可能 -->
  <div v-for="project in projects">{{ project.title }}</div>
</template>
```

## 使い分けの指針

### テンプレート内でのみ使用する場合
```vue
<script setup>
// 戻り値を代入しない（シンプル）
defineProps<{
  projects: Project[];
  status?: string;
}>();
</script>

<template>
  <!-- テンプレート内で直接使用 -->
  <div v-for="project in projects">{{ project.title }}</div>
</template>
```

**適用場面：**
- シンプルなprops定義
- テンプレート内でのみpropsを使用
- コードの簡潔性を重視

### スクリプト内でも使用する場合
```vue
<script setup>
// 戻り値を代入する（スクリプト内でも使用可能）
const props = defineProps<{
  projects: Project[];
  status?: string;
}>();

// スクリプト内でpropsを使用
const filteredProjects = computed(() => 
  props.projects.filter(p => p.status === props.status)
);

// props全体を監視
watch(() => props.projects, (newProjects) => {
  console.log('Projects changed:', newProjects);
}, { deep: true });
</script>

<template>
  <!-- テンプレート内でも使用可能 -->
  <div v-for="project in filteredProjects">{{ project.title }}</div>
</template>
```

**適用場面：**
- 複雑なprops定義
- スクリプト内でpropsを操作する必要がある
- props全体を監視する必要がある
- デバッグや開発時の可読性を重視

### 分割代入を使用する場合
```vue
<script setup>
// 分割代入で個別変数として使用
const { project, tickets } = defineProps<{
  project: Project;
  tickets: Ticket[];
}>();

// 個別の変数として使用
const projectTitle = computed(() => project.title);
const ticketCount = computed(() => tickets.length);
</script>
```

**適用場面：**
- 特定のpropsのみを頻繁に使用
- コードの可読性を向上させたい
- TypeScriptの型推論を最大限活用したい

## 実践的な例

### シンプルなケース
```vue
<script setup>
// テンプレート内でのみ使用
defineProps<{
  title: string;
  isVisible: boolean;
}>();
</script>

<template>
  <div v-if="isVisible">
    <h1>{{ title }}</h1>
  </div>
</template>
```

### 複雑なケース
```vue
<script setup>
const props = defineProps<{
  user: User;
  settings: Settings;
  items: Item[];
}>();

// 複雑なロジックでpropsを使用
const hasPermission = computed(() => 
  props.user.role === 'admin' || props.settings.allowUserAccess
);

const filteredItems = computed(() => 
  props.items.filter(item => 
    hasPermission.value || item.isPublic
  )
);
</script>
```

## まとめ

- **テンプレート内でのみ使用**: `defineProps()`の戻り値を代入しない（シンプル）
- **スクリプト内でも使用**: `const props = defineProps()`で明示的に代入
- **個別変数として使用**: 分割代入を活用
- **Vue 3の特別な仕様**: テンプレート内では自動的にアクセス可能
- **開発チームの一貫性**を保つことが最も重要
