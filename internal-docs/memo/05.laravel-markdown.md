# Laravel-Markdown

[github](https://github.com/GrahamCampbell/Laravel-Markdown)

## 選定理由

 - スターが多い
 - 最終更新ちょっと遠いけどissueが放置されてるとかでもないので安定していると判断
 - commonmarkラッパーでcommonmarkの方は最近も更新されているので良さそうと判断

## Install

```sh
composer require "graham-campbell/markdown:^16.0"
```

config/app.phpに追記

```php
'Markdown' => GrahamCampbell\Markdown\Facades\Markdown::class,
```

適用

```sh
/var/www/html # php artisan vendor:publish

 ┌ Which provider or tag's files would you like to publish? ───────────────┐
 │ Search...                                                               │
 │ Markdown                                                      │
 └──────────────────────────────────────────────────────────────┘

   INFO  Publishing assets.  

  Copying file [vendor/graham-campbell/markdown/config/markdown.php] to [config/markdown.php] ................................................. DONE
```

ここまでやってから「これフロントの仕事じゃね？」と思い当たったので解散
