## 実装内容の説明

NavItemのUsersをログインユーザーの権限で出し分けるために、以下の変更を行いました：

### 1. バックエンド側の変更

**`AppServiceProvider.php`** にて、Inertia.jsの共有データとしてユーザー情報を追加：
- ユーザーの基本情報（id、name、email、role）
- 権限チェック用のヘルパーメソッド（isAdmin、isManager）

### 2. フロントエンド側の変更

**`AppSidebar.vue`** にて：
- `usePage()`を使用してユーザー情報を取得
- `computed`プロパティを使用してリアクティブなナビゲーションアイテムを生成
- 管理者（`isAdmin`がtrue）の場合のみUsersメニューを表示

**`types/index.d.ts`** にて：
- Userインターフェースに`role`、`isAdmin`、`isManager`プロパティを追加

### 3. 動作の流れ

1. ユーザーがログインすると、`AppServiceProvider`でユーザー情報がInertia.jsに共有される
2. フロントエンドで`page.props.auth.user`を通じてユーザー情報にアクセス可能
3. `AppSidebar`コンポーネントで`computed`プロパティを使用して、管理者権限がある場合のみUsersメニューを表示

### 4. 権限の拡張

現在は管理者のみがUsersメニューを表示できますが、必要に応じて以下のように拡張可能です：

```javascript
// 管理者またはマネージャーが表示できる場合
if (page.props.auth?.user?.isAdmin || page.props.auth?.user?.isManager) {
    items.push({
        title: 'Users',
        href: index(),
        icon: User,
    });
}
```

この実装により、`UserPolicy`の`viewAny`メソッドと同様の権限制御がフロントエンドでも実現され、セキュリティが向上します。
