# プロジェクトとチケットの作成

## 概要・背景
- プロジェクト管理システムの基盤機能を構築する
- チーム内でのタスク管理とプロジェクト進行の可視化を実現する
- 管理者とメンバーの役割分担を明確化する

## 範囲・対象
- 管理者: プロジェクト作成・メンバー管理権限
- メンバー: チケット作成・表示権限
- スコープ外: チケット編集・削除、プロジェクト削除機能

## ゴール
- 管理者がプロジェクトを作成できる
- 管理者がプロジェクトにメンバーをアサインできる
- メンバーがプロジェクトにチケットを作成できる
- プロジェクトごとのチケット一覧が見える
- メンバーごとのチケット一覧が見える

## 完了条件・定義
- プロジェクト作成フォームが正常に動作する
- メンバーアサイン機能が動作する
- チケット作成フォームが正常に動作する
- チケット一覧表示が正確に動作する
- 基本的なUI/UXが整備されている

## リスク・課題
- 権限管理の複雑性
- データベース設計の適切性
- ユーザビリティの確保
